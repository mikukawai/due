# 匹配服务协议

> 版本：v1.0 | 最后更新：2026-08-05

本文档定义匹配、邀请房、观战和战绩相关协议。通信层包格式请参阅 **[通信协议规范（公共篇）](packet-protocol.md)**，登录认证请参阅 **[登录服务协议](login-protocol.md)**。

> **注意**：所有匹配相关协议都需要先完成登录（route=1001），否则返回 code=9。

---

## 1. 协议列表

| 协议号 | 方向 | 需登录 | 说明 |
|--------|------|--------|------|
| 2001 | C→S | **是** | 快速匹配 |
| 2002 | C→S | **是** | 取消匹配 |
| 2003 | S→C | — | 匹配成功（服务端推送） |
| 2004 | C→S | **是** | 请求观战列表 |
| 2005 | C→S | **是** | 加入观战 |
| 2006 | S→C | — | 结算通知（暂未实现） |
| 2007 | S→C | — | 观战房间列表（暂未实现） |
| 2008 | C→S | **是** | 创建邀请房 |
| 2009 | C→S | **是** | 加入邀请房 |
| 2010 | S→C | — | 邀请房已创建（2008 的 Response 直接返回） |
| 2011 | C→S | **是** | 查询战绩 |
| 2012 | S→C | — | 战绩返回（2011 的 Response 直接返回） |

---

## 2. 协议详细定义

### 2.1 快速匹配 — route=2001

加入匹配队列，等待配对。如有对手在队列中则立即配对，否则阻塞等待。

#### 请求

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| deck_id | string | 是 | 卡组 ID |

```json
{"deck_id": "deck_fire_001"}
```

#### 配对成功响应 (code=0)

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 = 成功 |
| ds_host | string | DS 服务器地址（当前 mock 为 127.0.0.1） |
| battle_port | int | DS 战斗端口（mock 为 7000） |
| room_key | string | 房间唯一标识 |
| player_token | string | 当前玩家的对战 token |
| player_id | int | 玩家在房间中的编号（0 或 1） |
| opponent_uid | int64 | 对手的用户 ID |

```json
{
    "code": 0,
    "ds_host": "127.0.0.1",
    "battle_port": 7000,
    "room_key": "a1b2c3d4-...",
    "player_token": "token_abc12345",
    "player_id": 0,
    "opponent_uid": 10002
}
```

#### 失败响应

```json
{"code": 6}
```

---

### 2.2 取消匹配 — route=2002

从匹配队列中移除自己。

#### 请求

```json
{}
```

#### 响应

```json
{"code": 0, "message": "match cancelled"}
```

---

### 2.3 匹配成功 — route=2003

**S→C 推送。** 配对成功时服务器向队列中等待的玩家推送。格式与 2001 成功响应一致。

---

### 2.4 观战列表 — route=2004

获取当前所有进行中的对战房间。

#### 请求

```json
{}
```

#### 响应

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 = 成功 |
| rooms | array | 房间列表 |
| rooms[].room_key | string | 房间 key |
| rooms[].uid1 | int64 | 玩家 1 uid |
| rooms[].uid2 | int64 | 玩家 2 uid |

```json
{
    "code": 0,
    "rooms": [
        {"room_key": "a1b2c3d4-...", "uid1": 10001, "uid2": 10002}
    ]
}
```

---

### 2.5 加入观战 — route=2005

加入指定房间进行观战。

#### 请求

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| room_key | string | 是 | 要观战的房间 key |

```json
{"room_key": "a1b2c3d4-..."}
```

#### 成功响应 (code=0)

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 = 成功 |
| ds_host | string | DS 服务器地址 |
| battle_port | int | DS 战斗端口 |
| room_key | string | 房间 key |

#### 失败响应

```json
{"code": 5}
```

---

### 2.6 创建邀请房 — route=2008

创建一个邀请房，返回 6 位邀请码。

#### 请求

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| deck_id | string | 是 | 卡组 ID |

```json
{"deck_id": "deck_water_002"}
```

#### 响应

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 = 成功 |
| invite_code | string | 6 位随机邀请码（大写字母+数字，排除 0O1I） |

```json
{"code": 0, "invite_code": "X7K2M9"}
```

---

### 2.7 加入邀请房 — route=2009

通过邀请码加入房间，配对创建者和加入者。

#### 请求

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| invite_code | string | 是 | 6 位邀请码 |
| deck_id | string | 是 | 卡组 ID |

```json
{"invite_code": "X7K2M9", "deck_id": "deck_fire_001"}
```

#### 成功响应 (code=0)

格式与 2001 成功响应一致。

#### 失败响应

```json
{"code": 5}
```

---

### 2.8 查询战绩 — route=2011

查询当前玩家的胜负统计。

#### 请求

```json
{}
```

#### 响应

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 = 成功 |
| wins | int | 胜场数 |
| losses | int | 败场数 |

```json
{"code": 0, "wins": 5, "losses": 2}
```

## 3. 错误码

| code | 含义 |
|------|------|
| 0 | 成功 |
| 3 | 请求参数格式错误 |
| 5 | 房间不存在 / 邀请码无效 |
| 6 | 服务器内部错误 / 匹配超时 |
| 7 | Token 无效（未登录） |
| 9 | 未登录时访问需授权协议 |
